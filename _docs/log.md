## 一、说明

> **写法约定**：只写最终结果和**根因**，不写"先做成 A 又改成 B"的返工过程，也不写验证数字。一条讲清"现在是什么样、为什么"即可。

## 二、版本与存储策略

本地 `Study-Math` 为唯一主版本，GitHub 仓库（rosy0905.github.io/Study-Math）为同步备份。学习数据（正误标记）存浏览器 IndexedDB（库名 `study-math-v3`），务必定期在网页"备份"处导出 JSON。新增章节须同步改 `index.html` 的脚本引用并把 `data/chapter1.js` 末的 `window.SEED_VERSION` +1，否则浏览器看不到新题。

## 三、已录入章节与修订

### 26/10/06 · 项目启动 + 第一章

（1）搭站：纯 HTML/JS 无构建，照搬经济学/英语家族骨架（IndexedDB 存储、五瓣花图标只换色槽、公式存 `$...$` 源码 + 落库前还原），建 `index.html`/`app.js`/`db.js`/`chapters.js` 与首批 demo。

（2）章节口径：侧栏只显示 13 个大章节，数三只学前 8 章（4/9/10/11/12 章数一不学），`chapters.js` 用 `num3` 标记过滤；卡片题号按两级数字自然序（如 `1.10` 排在 `1.8` 后）。

（3）UI 定型：卡片改单列通栏、编辑弹窗三段式、导出按钮语义改为"数据管理"；大幅精简只留浏览 + 正误三档（未做/正确/错误）。正误按钮最终弃用原生 `<select>`（跨浏览器锯齿条不可靠），改自绘按钮 + 弹层，CSS 类名一律 ASCII。

（4）公式渲染根因：公式内裸 `<` `>` 被浏览器当 HTML 标签吃掉，统一写 `\lt`/`\gt`（命令+空格）；单反斜杠会被 JS 转义吃掉，数据一律用 `JSON.stringify`/`chr(92)` 生成，不用正则改 JS 里的 LaTeX。

（5）第一章首录：题面/答案全部改为 PDF 原文（初版自编的 1.8 等已重做），pageNo 改用 PDF 实际页码；按用户文档标注清单录入，不自行连续外推。
