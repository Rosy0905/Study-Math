## 一、字段与 HTML 格式

### 1.1 八个字段（缺一不可）
```js
{ id:'2.7', originalNo:'2.7', chapter:'2', pageNo:'72',
  type:'单选', isRealExam:true, problemHTML:'…', answerHTML:'…' }
```
- `pageNo` **必须是字符串**（`'72'`，不是数字）
- `type` **仅三值**：`单选` / `填空` / `解答`（禁用「选择题 / 填空题 / 解答题」）
- `id` 全局唯一，格式 `章.题号`

### 1.2 problemHTML / answerHTML
| 规则 | ✅ | ❌ |
|------|-----|-----|
| 不重复题号 | `（2000 数三）设函数…` | `<b>【2.7】</b>…` |
| 不用 `<p>` | 纯文本 + `\n` 换行 | `<p>…</p>`（撑高卡片、紧凑度不一致） |
| 答案开头 | `<b>答：B</b>` / `<b>解：</b>` | `<b>【解析】选（B）</b>` |

### 1.3 答案内容
- 每步用 `<b>第N步：</b>` 标注
- 原书红笔批注 / 打叉照实写出
- 原书简写或不严谨处**不照抄**，用「易错提醒」标出并给严格推导
- 原书写「见视频课」/ 答案缺失的题，**必须自己补完整解答**（照抄「见视频课」= 没答案）

### 1.4 ⚠️「（补充过程）」——头号翻车点
**只有「原书完全没有文字答案」才标；自己把解答写详细 ≠ 补充过程。**
- 判定：先扫答案册文本层，再看**下一页顶部 3%–20%**（答案册常跨页，只看本页页尾会误判成无过程）；只有「本页 + 下页顶都无推导」才标
- 写法：标记紧跟冒号 ✅ `<b>答：（补充过程）B</b>` / `<b>解：（补充过程）</b>`；❌ 不能塞在答案值后
- 撤回：勿用 `replace('：（补充过程）','')`（会吞冒号变 `<b>答A</b>`）；用正则 `^(<b>)([答解])([^：<])` 把冒号补回

### 1.5 序列化
用 `JSON.stringify(v)` 输出（转义可靠）；**不要手拼 `'…\n'+'…'`**（转义事故频发）。

## 二、LaTeX 铁律（违反即不渲染）
- **2.1 禁裸 `<` `>`**：用 `$a \lt b$` / `$x \gt 0$`（命令后必须跟**空格**）；`\le` / `\ge` 不受影响
- **2.2 双反斜杠**：源码写 `\\gt` `\\alpha`；单反斜杠被 JS 吃掉 → `Undefined control sequence`
- **2.3 数学必须包 `$…$`**：尤其答案首行 `<b>答：\dfrac{1}{e}</b>` 里的公式最容易漏包，漏了 KaTeX 扫不到
- **2.4 别用 Python 正则改 JS 里的 LaTeX**：`\gt` 是双字符，正则只匹配单反斜杠会吃掉转义 → 整份重写（Write）或用 Node eval 后改
- **2.5 `\big\{` 误判**：改用 `\left\{ … \right\}'`；批量 `\big`→`\left` 时**只换 `\{ \}` `[ ]`**，别动 `\big|` `\big.`（否则 `\left`/`\right` 不配对）

## 三、四道审核（缺一不可）

> 核心：读题与验算是**两道独立关**。题目抄错 → 验算必然跟着错。

1. **读题**（结构件 700–850dpi 放大）：确认根号次数 / 上下标 / 绝对值 / 幂次 / 指数位置；**200dpi 整页图一律不信**（曾误读 6 处、原书零错）。另用 sympy 求导复核：`simplify(diff(答案, x) - 题面)` == 0（根式假差用 `sp.N(subs(x, 1/2), 12)` 数值验证）。题号正则须容忍空格 `【\s*3\s*\.\s*(\d+)\s*】`；含 `cases` 的分式重点核对；裁切向上留 34pt。
2. **独立验算**：不看原书答案先算一遍，再对照。
3. **⚠️ 怀疑自己**：书印答案极少错，不符时**先 600–700dpi 复核**再判「原书错」；参数方程 / 绝对值 / 分式一律 700dpi；认准【题号】再裁，别凭「大概是这题」（曾把上一题解析当本题）。
4. **机器校验（必须全绿）**：
   ```bash
   sed "s|data/chapter2.js|data/chapterN.js|" _v2.js > _vN.js
   sed "s|data/chapter1.js|data/chapterN.js|" _katex_check.js > _katex_checkN.js
   node _vN.js              # $配对 / 裸尖括号 / 括号平衡 / 控制字符
   node _katex_checkN.js    # KaTeX 真实渲染：必须 0 错误
   node -e "global.window={};eval(require('fs').readFileSync('data/chapterN.js','utf8'));console.log(window.SEED_PROBLEMS.length)"
   ```
   校验器须派生自 `_v2.js`（正确处理 `$$…$$`，否则跨行显示公式留悬空 `$` 吞 `<b>` → 假阳性）。

## 四、新增章节接入
```js
window.SEED_PROBLEMS = window.SEED_PROBLEMS || [];   // 用 push 累积，勿 =[]
window.SEED_PROBLEMS.push( /* … */ );
```
1. `index.html` 加 `<script src="data/chapterN.js"></script>`（chapter1.js 之后）
2. `data/chapter1.js` 末尾 `window.SEED_VERSION = N;` → **+1**（版本不动 = 浏览器不刷新新题）
3. 端到端：两章 eval 确认无重复 id / 字段无缺 / 排序正确
4. 本地 **Ctrl+Shift+R** 硬刷新触发重灌

## 五、页码与 PDF 定位
- **答案册 ≠ 数三册**，两本页码不通用；口径先跟用户确认按哪本
- 答案册题号标 `【章.题号】`，`2.x` 连续编号；**例题无 `【例N】` 标记**（录入第二章例题时 id 用 `中值例N`，`例题N` 已被第一章占用）
- **书印页 ≠ PDF 页**：别从 `get_text()` 猜页码（文本流含水印 / 页脚装饰数字）
- PDF：`get_text()` 因 ToUnicode 不全会乱码，但**数字与题号正常**；手写体答案为矢量线条，**只能渲染页面逐题识读**
